# PRADAS Data Directory

## Structure

- `input/` — Place your input video files here (not tracked in git).
- `output/` — Processed output videos are saved here (not tracked in git).
- `samples/` — Sample data for testing and demonstration.

## Obtaining Test Videos

You can use any road/traffic video. Recommended sources:

1. **Record your own** using a dashcam or phone (safest option).
2. **Public datasets** (check licenses before use):
   - JAAD (Joint Attention in Autonomous Driving)
   - PIE (Pedestrian Intention Estimation)
   - nuScenes (requires registration)
3. **Stock footage** from Creative Commons sources.

## Important

- Do NOT commit large video files to the repository.
- Respect privacy and copyright of any video data.
- This directory is listed in `.gitignore`.
